## 🎯 Quick Tips

### For Best Results
1. **Speak Clearly**: Pronounce words clearly
2. **Normal Speed**: Don't speak too fast or slow
3. **Quiet Place**: Reduce background noise
4. **Wait**: Wait for green indicator before speaking
5. **Natural**: Speak naturally, not robotically

### Visual Indicators
- **Gray Button**: Click to start
- **Green Button**: Listening (speak now)
- **Green + Pulse**: Voice detected
- **Blue**: Processing
- **Red**: Error (try again)

## 🔧 Troubleshooting

| Problem | Solution |
|---------|----------|
| Mic access denied | Allow in browser settings |
| No speech detected | Speak louder, check mic |
| Command not recognized | Use simpler phrases |
| Not working | Update browser, check internet |

## 📱 How to Use

1. **Click** the microphone icon (🎤) in header
2. **Wait** for green indicator
