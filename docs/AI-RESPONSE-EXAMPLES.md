## How It Works Behind the Scenes

When user asks: "Show me my current sales"

1. **AI reads RAG context** from `.kiro/steering/sales-context.md`
2. **AI recognizes** this is a sales query
3. **AI decides** to call `/api/sales/aggregated`
4. **API fetches** data from all stores
5. **AI receives** structured JSON data
6. **AI formats** response with emojis, currency, percentages
7. **User sees** beautiful, informative response

---

You can customize responses by editing:
